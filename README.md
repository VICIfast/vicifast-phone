# VICIfast Phone

The agent phone app for VICIdial call centers on [VICIfast](https://vicifast.com),
for Android (iPhone to follow).

The app is free software under the **GNU General Public License, version 3**
(see [LICENSE](LICENSE)). It is built on [linphone-sdk](https://linphone.org),
also GPLv3.

The complete source of every release is published here, tagged `v<version>`,
when that release is made available. The first release is on its way.
